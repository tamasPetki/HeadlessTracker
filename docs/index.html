The problem it solves

If you hold assets across multiple exchanges, wallets, and prediction markets, your morning ritual is five tabs and ten logins. HeadlessTracker aggregates everything into a single MCP server. Then you just ask your AI host.

Building yet another dashboard UI is wasted work in 2026. Build the data layer — let the AI host be the renderer.

How it works

1

Add your accounts via the setup CLI

API keys and wallet addresses stored in your system keychain — nothing leaves your machine.

2

Wire it into Claude Desktop (or any MCP host)

One JSON entry in your MCP config. Claude Desktop, Claude Code, Cursor, and ChatGPT all work.

3

Ask questions in plain language

"What do I own?" — "Show my Bybit P&L this week." — "How much is in Polymarket?"

Connectors

Five data sources, one unified schema.

Bybit
Spot + futures, full transaction log, fees, interest
Binance
Spot + futures positions and balances
MetaMask / EVM
6 chains, multi-wallet, native + ERC-20 transfers
Solana
Multi-wallet, SPL tokens, on-chain balances
Polymarket
Open positions, trades, P&L by market

Quick start

# Install
npm i -g headless-tracker

# Add your first account
headless-tracker setup

# Add to Claude Desktop config (~/.claude/claude_desktop_config.json)
{
  "mcpServers": {
    "headless-tracker": {
      "command": "headless-tracker"
    }
  }
}

Requires Bun ≥ 1.3. See the full README for per-connector setup.
